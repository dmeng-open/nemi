# User flows

One page per product version. Add `vN.md` when that version’s user-visible loop is settled.

These pages describe what a person does and what they see. They are not the implementation plan and not the provider setup guide.

- [V0](v0.md) — local demo world. Mock events and restaurants, a calendar stored in Nemi, and an `.ics` download.
- [V1](v1.md) — the same planning loop, with optional Ticketmaster, Google Places, and Google Calendar. Demo mode still works with no keys.

Architecture and decisions: [architecture.md](../architecture.md). Keys and OAuth setup: [integrations.md](../integrations.md).
